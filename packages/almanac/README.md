# almanac

A publishing framework for technical and scientific writing, built as an Astro
integration. Documentation, a blog, search, and 42 themes from a directory of
Markdown, with optional layers for code that runs at build time, MyST syntax, and
PDF output.

Full documentation: **https://shravangoswami.com/almanac/**

```bash
npm install almanac satori @resvg/resvg-js pagefind
```

```js
// astro.config.mjs
import { defineConfig } from "astro/config";
import almanac from "almanac";

export default defineConfig({
	site: "https://example.com",
	integrations: [
		almanac({
			title: "My Project",
			social: { github: "https://github.com/you/your-project" },
		}),
	],
});
```

```ts
// src/content.config.ts
import { defineCollection } from "astro:content";
import { blogLoader, blogSchema, docsLoader, docsSchema } from "almanac/content";

export const collections = {
	docs: defineCollection({ loader: docsLoader(), schema: docsSchema() }),
	blog: defineCollection({ loader: blogLoader(), schema: blogSchema() }),
};
```

Write `docs/index.md` and the route exists.

Or scaffold the whole thing:

```bash
npm create almanac@latest my-docs
```

## What you get by default

Docs routing with an explicit or autogenerated sidebar, previous and next paging,
a scroll-spy table of contents, [Pagefind](https://pagefind.app/) search, an
optional blog with tags and RSS, 42 themes with a light and dark pair each, a
build-time OG image, and a link and anchor checker that runs after every build.

## What is opt-in

Each of these is a bigger commitment than rendering Markdown, so each is a flag:

- **`future.execute`** runs fenced blocks marked `exec` during the build and
  embeds their real output, cached on the code, the language, and the runtime
  version. JavaScript and TypeScript run natively, Python through Pyodide, R
  through WebR, and anything else on a Jupyter kernel you point it at.
- **`future.myst`** parses through a [MyST](https://mystmd.org/) AST: cross
  references that write their own text, numbered figures, directives, roles, and
  math.
- **`future.pdf`** typesets every page with [Typst](https://typst.app/) from the
  same tree the web page came from, so the PDF cannot disagree with the page.
  Optionally the whole site as one book with a cover and a clickable outline.
- **`versions` and `i18n`** publish old versions and translations that inherit
  unchanged pages instead of copying them, in a single build.

The heavier runtimes are optional peer dependencies, so a project pays only for
what it turns on.

## Status

Pre-1.0 and maintained by one person. It builds its own documentation site, which
is the best evidence available. R, Jupyter kernels, versioning, translations, and
PDF output all work; installing packages into Pyodide or WebR, citations, and
bibliographies do not yet.
