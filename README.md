# Almanac

A publishing framework for technical and scientific writing. Docs, blog, and
executable content from one source.

Status: early. See [PLAN.md](./PLAN.md) for the full architecture and roadmap.

## Layout

| Path | What it is |
|---|---|
| `packages/almanac` | The framework: Astro integration, config schema, content collections, themes, components |
| `packages/create-almanac` | Scaffolder CLI |
| `starter` | The owned source tree a new site starts from |
| `www` | The dogfooded site |
