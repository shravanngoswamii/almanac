# Almanac

A publishing framework for technical and scientific writing. Docs, blog, and
executable content from one source.

> Early days. The web renderer works and is dogfooded by this repository's own
> site. Executable code, MyST, and PDF output are next. See [PLAN.md](./PLAN.md)
> for the architecture and roadmap.

## Quick start

```bash
npm create almanac@latest my-docs
cd my-docs
npm run dev
```

That gives you docs routing, a sidebar, instant search, a table of contents,
40+ themes, and an OG image, from two things you own: `astro.config.mjs` and
whatever Markdown you put in `docs/`.

## Adding it to an existing Astro project

```bash
npm install almanac satori @resvg/resvg-js pagefind
```

```js
// astro.config.mjs
import { defineConfig } from "astro/config";
import almanac from "almanac";

export default defineConfig({
	integrations: [
		almanac({
			title: "My Project",
			social: { github: "https://github.com/you/your-project" },
		}),
	],
});
```

```ts
// src/content.config.ts
import { defineCollection } from "astro:content";
import { blogLoader, blogSchema, docsLoader, docsSchema } from "almanac/content";

export const collections = {
	docs: defineCollection({ loader: docsLoader(), schema: docsSchema() }),
	blog: defineCollection({ loader: blogLoader(), schema: blogSchema() }),
};
```

Write `docs/index.md` and the route exists.

## Configuration

Config is validated with Zod, so a typo fails the build with the path of the
problem instead of rendering a broken page.

```js
almanac({
	title: "My Project",
	tagline: "Short line under the title.",
	description: "Used for meta tags and search.",
	author: { name: "You", url: "https://example.com" },
	social: { github: "...", sponsor: "...", x: "...", email: "..." },
	editUrl: "https://github.com/you/repo/edit/main/{path}",

	docs: {
		enabled: true,
		path: "docs",        // where the Markdown lives
		base: "docs",        // URL segment; "" serves docs at the root
		pager: true,
		toc: { minDepth: 2, maxDepth: 3 },
		sidebar: [           // omit to group by directory automatically
			{ label: "Get started", items: ["index", "start/install"] },
			{ autogenerate: { directory: "reference" } },
		],
	},

	blog: { enabled: true, postsPerPage: 8, rss: true, tags: true },

	theme: {
		default: "almanac-light",
		include: "all",      // or ["dracula", "nord"] to narrow the picker
		customCss: ["./src/custom.css"],
	},

	search: { provider: "pagefind" },
	components: { Header: "./src/overrides/Header.astro" },
	onBrokenLinks: "warn",
	future: { myst: false, execute: false },
});
```

### Sidebars

An entry can be a doc id, an explicit doc, an external link, a category, or an
autogenerated directory. Categories nest, which is why the schema is Zod rather
than Joi: recursive shapes need `z.lazy()`.

```js
sidebar: [
	"index",
	{ doc: "start/install", label: "Install" },
	{ link: "https://astro.build", label: "Astro" },
	{ label: "Guides", items: ["guides/a", { label: "Deep", items: ["guides/b"] }] },
	{ autogenerate: { directory: "reference", collapsed: true } },
]
```

Leave `sidebar` out and pages are grouped by their top-level directory, sorted
by `sidebar.order` then alphabetically.

### Frontmatter

```yaml
---
title: Required
description: Optional, used for meta tags and search
sidebar:
  label: Shorter label
  order: 2
  badge: New
  hidden: false
template: doc      # or "splash" for a landing page with no sidebar or TOC
draft: false
---
```

## Themes

42 themes ship built in: the Almanac default plus twelve color families and
eight signature palettes (Dracula, Nord, Gruvbox, Solarized, Sepia, One, Tokyo
Night, Catppuccin), each in both light and dark. Every family has a sibling in
the other mode, which the test suite enforces.

## Layout

| Path | What it is |
|---|---|
| `packages/almanac` | The framework: integration, config schema, collections, themes, components, routes |
| `packages/create-almanac` | Scaffolder CLI |
| `starter` | The tree a new site starts from, kept building in CI |
| `www` | This project's own site, built with the framework |
